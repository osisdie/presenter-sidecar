# Pre-talk checklist

## 30 minutes before

- [ ] Windows display mode is **Extend** (Win+P), not Duplicate.
- [ ] HDR is off on the laptop display (captured colours look washed out with HDR).
- [ ] Notifications off: Focus / Do not disturb.
- [ ] Close private tabs and windows you do not want to pick by accident.
- [ ] Browser zoom set so text is readable from the back row (Ctrl + plus).

## 10 minutes before

- [ ] Run `start.bat`. The panel opens on the right; the projector shows the blank screen.
- [ ] Click the browser you will present from and press **F7**. The panel shows its title.
- [ ] Press **Shift+F7** to put it next to the panel.
- [ ] Try F8 (freeze), F9 (blank), F10 (spotlight) once.
- [ ] Ctrl+Alt+PgDn / PgUp pages these notes without leaving the browser.

## Online sharing (Meet / Teams / Zoom)

- [ ] Share **entire screen → display 2** (the projector), never display 1.
- [ ] Before you start, press F9 and check what remote people see.

## After the talk

- [ ] Run `stop.bat`. It only closes what `start.bat` opened.
